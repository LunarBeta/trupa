# 🎸 Căutăm membri pentru trupă

Formular de aplicare pentru muzicieni (chitară, bas, tobe, clape, voce…) — Chișinău.

- Site: https://lunarbeta.github.io/trupa/
- Coduri QR pentru afișe: https://lunarbeta.github.io/trupa/qr.html

Aplicările ajung într-un Google Sheet privat (prin Google Apps Script). Linkul backend-ului e în `config.js`.
